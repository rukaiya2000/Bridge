## Rules

- **Use existing libraries, software or APIs before writing code.** If a well-maintained library, tool, service or API already does the job, use it instead of hand-rolling it. That includes platform APIs (Chrome extension APIs, browser APIs, Gemini API, MongoDB features) as well as third-party ones. Write custom code only for what's specific to Bridge (for example the site adapters and the scoring rules), and say which library or API you considered when you do.
